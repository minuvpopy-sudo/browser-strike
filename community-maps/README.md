# Карты сообщества Browser Strike

Игрок отправляет JSON-карту через шаблон GitHub Issue. После проверки файл добавляется в эту папку, а запись о нём — в `index.json`.

Требования:

- формат `browser-strike-map`;
- размер до 20 МБ;
- не более 500 объектов после проверки игрой;
- только собственная работа автора;
- без исполняемого кода и внешних текстур.

Игра загружает каталог без ключей доступа. Запись в репозиторий выполняется только после модерации владельцем.
