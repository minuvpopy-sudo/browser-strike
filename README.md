# Browser Strike: Sandstorm

**Играть онлайн:** <https://minuvpopy-sudo.github.io/browser-strike/>

Browser Strike — браузерная 3D-игра от первого лица на Three.js. Доступны одиночные матчи с ботами и сетевые комнаты 1 на 1: две команды, карта `de_sandstorm2`, раунды, экономика, покупка оружия и режим установки бомбы.

## Онлайн 1 на 1 с другом

1. Откройте опубликованную игру и нажмите **«Онлайн 1 на 1»**.
2. Первый игрок вводит имя, нажимает **«Создать»** и отправляет другу шестизначный код.
3. Второй игрок открывает ту же страницу, вводит имя и код, затем нажимает **«Подключиться»**.
4. После соединения матч запускается автоматически: хозяин комнаты играет за террористов, второй игрок — за спецназ.

Онлайн-режим использует WebRTC: сервер PeerJS помогает найти комнату, а игровые данные затем передаются напрямую между браузерами. Обоим игрокам нужен интернет.

## Быстрый запуск в Windows

1. Установите актуальную LTS-версию Node.js с сайта <https://nodejs.org/>. В установщике оставьте включённым добавление Node.js в PATH.
2. Распакуйте папку `browser-strike` в удобное место.
3. Откройте папку и дважды щёлкните `start.bat`.
4. При первом запуске скрипт установит компоненты. Затем он дождётся готовности сервера и откроет игру по адресу <http://127.0.0.1:5173>.
5. Чтобы остановить сервер, закройте свёрнутое окно `Browser Strike Server`.

`start-simple.bat` запускает уже установленный проект, не выполняя повторную установку. Если папка `node_modules` отсутствует, используйте обычный `start.bat`.

Нельзя надёжно запускать игру двойным кликом по `index.html`: браузеры запрещают части загрузки JavaScript-модулей и ресурсов через протокол `file://`. Нужен локальный HTTP-сервер, который и запускают BAT-файлы.

## Команды разработчика

```text
npm install
npm run dev
npm test
npm run build
npm run preview
```

Development-адрес: `http://127.0.0.1:5173`. Preview-адрес production-сборки: `http://127.0.0.1:4173`.

После `npm run build` готовые файлы находятся в `dist`. Их можно запустить без Vite командой `start-production.bat`; используется маленький сервер `server.mjs`, адрес — `http://127.0.0.1:8080`.

## Что реализовано

- Главное меню в стилистике начала 2000-х, выбор команды, режима и ножа.
- Режимы «Закладка бомбы» и «Командный бой».
- Онлайн-комнаты 1 на 1 с кодом, синхронизацией движения, оружия, стрельбы, урона, смертей, возрождений и пинга.
- Оригинальная карта `de_sandstorm2`, собранная из примитивов: две базы и точки, центр, двери, длинный/короткий маршруты, тоннели, ящики, рампы и альтернативные проходы.
- Встроенный 3D-конструктор карт: стены, ящики, проходимые рампы, арены размером до 480×480, точки T/CT и плэнты A/B; объекты получают коллизии и навигацию для ботов.
- Локальная мастерская карт с сохранением в браузере, выбором карты для одиночного матча и обменом через экспорт/импорт JSON.
- Движение с ускорением, торможением, инерцией, air control, прыжком, приседанием, ходьбой и столкновениями.
- Pointer Lock, обзор мышью, переназначение клавиш, пауза по Esc.
- 24 модели огнестрельного оружия в классическом low-poly стиле, стандартный нож, нож-бабочка и керамбит.
- Hitscan-стрельба, магазины и запас патронов, перезарядка, динамический разброс, отдача, зоны попадания, броня и шлем.
- Процедурные low-poly модели оружия и персонажей; процедурные материалы и синтезированные Web Audio API звуки.
- Классическое меню покупки с мгновенной покупкой одним нажатием, проверкой стороны, денег, стартовой зоны и времени покупки.
- Экономика раундов с лимитом денег, наградами и бонусом серии поражений.
- Боты с конечным автоматом, задержкой реакции, уровнями сложности, проверкой прямой видимости и A*-навигацией.
- Установка/обезвреживание бомбы, набор сапёра, таймер, сигналы, взрыв и урон по радиусу.
- Осколочная, светошумовая, дымовая и ложная гранаты с отдельными моделями и эффектами.
- HUD, радар, убийства, таблица счёта, таймер, счёт команд и сообщения.
- Настройки игры, управления, графики и звука с сохранением в `localStorage`.

## Управление

`WASD` — движение; мышь — обзор; ЛКМ — огонь/атака/бросок гранаты; ПКМ — прицел/тяжёлая атака; `R` — перезарядка; `Space` — прыжок; `Ctrl` — приседание; `Shift` — шаг; `E` — установка или обезвреживание; `B` — покупка; `Q` — предыдущее оружие; `G` — выбросить; `F` — осмотр; `1/2/3` — основное/пистолет/нож; `4` — взять гранату, повторное нажатие меняет её тип; `M` — выбор команды на следующий матч; `N` — выбор ножа; `Tab` — таблица; `Esc` — пауза.

## Изменение проекта

Все исходники — обычные текстовые HTML/CSS/JS-файлы и открываются в Notepad++.

- Карта: редактируйте координаты стен, ящиков, точек появления, зон и навигационных узлов в `src/map/MapConfig.js`. Геометрия создаётся в `src/map/DustInspiredMap.js`.
- Карты игроков: откройте в главном меню **«Конструктор карт»**, создайте карту, нажмите **«Сохранить»**, затем **«Выбрать»**. Инструмент **«Рампа»** создаёт настоящий подъём; направление высокой стороны выбирается в свойствах. **«Очистить всё»** удаляет со сцены все объекты после подтверждения. Кнопка **«Скачать JSON»** создаёт файл для публикации или отправки другу, а **«Импорт JSON»** добавляет полученную карту в мастерскую.
- Оружие: цены, урон, темп, магазины, перезарядка, разброс, отдача, скорость и дальность находятся в `src/weapons/WeaponDefinitions.js`.
- Оформления оружия: добавьте палитру в `src/skins/WeaponSkinDefinitions.js` и её идентификатор в меню.
- Ножи: палитры находятся в `src/skins/KnifeSkinDefinitions.js`; геометрия предпросмотра — в `src/skins/SkinPreview.js`, модель от первого лица — в `src/weapons/WeaponManager.js`.
- Боты: уровни реакции и точности задаются в `src/bots/BotCombat.js`; маршруты — в `MapConfig.js`; логика состояний — в `src/bots/BotAI.js`.
- Пользовательские ресурсы: укажите законно полученные относительные пути в `public/user-assets.json`. При пустом файле игра использует только программные ресурсы.

## Ограничения текущей версии

- Карта воспроизводит знакомую трёхмаршрутную логику, но не является точной копией какой-либо коммерческой карты.
- Модели процедурные и не имеют скелетной анимации; перезарядка, отдача и осмотр анимируются трансформациями частей.
- Боты используют гранаты и укрытия упрощённо; сложная командная тактика и прострел поверхностей ограничены.
- Дым учитывается ботами как преграда видимости, но визуально состоит из простых объёмов.
- В сетевой комнате сейчас доступен командный бой 1 на 1; боты и режим бомбы остаются в одиночной игре.
- Пользовательские карты в этой версии выбираются для одиночной игры. Для общей публичной ленты мастерской и автоматической загрузки карт по ссылке понадобится серверное хранилище; на GitHub Pages обмен работает через JSON-файлы.
- На некоторых строгих корпоративных или мобильных сетях прямое WebRTC-соединение может блокироваться настройками сети.

## Авторские ресурсы

Проект не содержит BSP-файлов, геометрию, модели, текстуры, звуки, интерфейсные изображения, скины или логотипы Counter-Strike/Valve. Вся геометрия создаётся кодом Three.js, текстуры — процедурно через Canvas API, звуки — через Web Audio API.
